# Contributing

## Setup

```sh
npm ci
npm run dev
```

The app talks to the Supabase project in `.env` (see `.env.example`).

## Before opening a pull request

```sh
npm run lint
npm run build
```

CI runs the same checks on every pull request.

## Things to know

- **Lovable** commits straight to `main`. Pull before you start, and keep pull requests small so they merge cleanly.
- **Database changes** go in a new file in `supabase/migrations/`. Never edit a migration that has already run.
- **`src/components/ui/`** is generated by shadcn-ui. Prefer re-generating a component to hand-editing it.
- **The TV display** (`/tv`) runs unattended for hours: watch out for timers, subscriptions and anything that leaks over time.
